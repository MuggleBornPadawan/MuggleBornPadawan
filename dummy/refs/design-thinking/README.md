# Design Thinking Project Template

A standardized framework for applying Design Thinking across portfolio projects, ensuring consistency, rigor, and user-centric decision-making from initial problem discovery to post-launch evaluation.

---

## 🧭 Design Thinking Lifecycle

This repository provides plain Markdown templates covering all 5 stages of the Design Thinking process:

| Stage | Document | Purpose |
| :--- | :--- | :--- |
| **01. Empathize** | [`templates/01-empathize.md`](templates/01-empathize.md) | Discover user needs, build empathy maps, and define core user personas. |
| **02. Define** | [`templates/02-define.md`](templates/02-define.md) | Define product requirements (PRD), scope boundaries, and key success metrics. |
| **03. Ideate & Architecture** | [`templates/03-ideate-architecture.md`](templates/03-ideate-architecture.md) | Document system design, technical trade-offs, stack decisions, and data flow. |
| **04. Prototype & Build Plan** | [`templates/04-prototype-build-plan.md`](templates/04-prototype-build-plan.md) | Break down implementation phases, milestones, tasks, and risk mitigations. |
| **05. Test & Evaluate** | [`templates/05-test-evaluate.md`](templates/05-test-evaluate.md) | Execute verification plans, collect feedback, evaluate metrics, and conduct retrospectives. |

---

## 📚 Supporting Guides

* **[Implementation Guide (`GUIDE.md`)](GUIDE.md)**: Detailed phase-by-phase instructions on how to use each template effectively.
* **[Template Configuration (`.template-config`)](.template-config)**: Best practices for copying or integrating these templates into new portfolio projects.

---

## 🚀 Quick Start

1. Copy the `templates/` folder into your target project's root directory.
2. Fill out `01-empathize.md` and `02-define.md` during project kickoff.
3. Complete `03-ideate-architecture.md` and `04-prototype-build-plan.md` before writing code.
4. Maintain `05-test-evaluate.md` during testing, launch, and post-launch reviews.
