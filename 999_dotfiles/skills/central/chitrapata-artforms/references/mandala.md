# Mandala — Algorithmic Specification

> Radial Symmetry Family · Geographic Locus: Pan-Indian, Tibetan Himalayan plateau

## Core Algorithm

Recursive concentric ring shape grammar with dihedral symmetry replication.

### Pipeline

1. **Bindu Seed**: Place a central point at origin `[0.0, 0.0]`. This is the cosmological seed — all geometry radiates outward from here.
2. **Ring Generation**: Generate `k` concentric annular rings at radii `[r_1, r_2, ..., r_k]`. Each ring occupies the annular band between `r_i` and `r_{i+1}`.
3. **Motif Sector**: Within each ring, define a single angular sector spanning `[0, 2*pi/n]` radians. Fill this sector with the ring's motif grammar (petal arcs, dot arrays, geometric lattice tiles, or nested sub-mandalas).
4. **D_n Replication**: Rotate the motif sector `n` times by `2*pi/n` to fill the complete annulus. This enforces strict dihedral symmetry group D_n.
5. **Square Outer Boundary**: Clip the outermost ring against a square perimeter aligned to `[-1.0, 1.0]` bounds. The mandala is round inside a square frame — this is structurally essential.
6. **Torana Gates**: Cut four rectangular openings in the square perimeter at cardinal directions (0, pi/2, pi, 3*pi/2). These are the T-shaped directional portals.
7. **Color Assignment**: Map pigments to rings. Alternate warm/cool palettes across adjacent rings for visual vibration.

### Motif Sub-Grammar (per ring)

Each ring's sector content is generated by a recursive sub-grammar with depth `d_motif`:

- **Depth 0**: Simple geometric fill (solid color band, dot row, or line border).
- **Depth 1**: Petal arc arrays — semicircular arcs with cusps pointing outward.
- **Depth 2**: Nested petal arrays with interior hatching or alternating color fills.
- **Depth 3+**: Fractal subdivision — each petal contains a smaller motif ring (recursive self-similarity).

The sub-grammar is parameterized per ring, allowing heterogeneous complexity across the mandala.

## Visual Invariants (MUST Hold for Recognition)

These are hard constraints. If any is violated, the output is NOT a valid mandala:

1. **Perfect n-fold rotational symmetry**: Every ring must be exactly D_n symmetric. Zero tolerance for asymmetric placement.
2. **Square outer boundary**: The outermost frame is a square, not a circle. This distinguishes mandala from generic radial art.
3. **Four torana gates**: Exactly four portal openings at cardinal axes. Not three, not five.
4. **Central bindu**: A visible point or small circle at the exact center. Never empty.
5. **Dense fill**: No negative space within rings. Every annular band must contain motifs. (Negative space exists ONLY between the circular rings and the square boundary corners.)
6. **Outward radiation**: Visual complexity increases from center outward. Inner rings are simpler, outer rings are more elaborate.

## State Parameters & Invariants

```clojure
{:symmetry-order  8        ;; n in {4, 8, 12, 16} — maps to dihedral group D_n
 :ring-count      5        ;; k in [3, 12] — number of concentric rings
 :ring-radii      [0.08 0.18 0.35 0.55 0.78]  ;; ascending, all < 1.0
 :torana-width     0.12     ;; angular width of gate openings, in [pi/24, pi/8] radians
 :torana-depth     0.06     ;; radial depth of T-shape cutout
 :motif-depths    [0 1 2 2 3]  ;; recursion depth per ring, in [0, 4]
 :petal-count-per-ring [4 8 8 16 16]  ;; petal arcs per sector, per ring
 :phase-offsets   [0.0 0.0 0.196 0.0 0.196]  ;; angular offset per ring (radians), for visual staggering
 :bindu-radius    0.03     ;; radius of central seed circle
 :palette         [:lapis-lazuli :vermilion :malachite :conch-white :gold-leaf]}
```

### Parameter Constraints

- `ring-radii` must be strictly ascending: `r_1 < r_2 < ... < r_k`.
- `symmetry-order` must be a multiple of 4 (mandala tradition uses quadrant-based symmetry).
- `petal-count-per-ring[i]` must be a divisor of `symmetry-order` (or the same value) to tile evenly.
- `phase-offsets` alternate rings create visual staggering — adjacent rings should differ by `pi/n` or `0`.

## Clojure Pseudocode

```clojure
(ns art.artforms.mandala
  "Pure mandala generator. No renderer imports.")

(defn make-rng [seed] (let [r (java.util.Random. (long seed))] #(.nextDouble r)))

(defn polar->cart
  "Convert (r, theta) to [x, y]."
  [r theta]
  [(* r (Math/cos theta))
   (* r (Math/sin theta))])

(defn petal-arc
  "Single petal arc primitive in a sector."
  [center radius start-angle end-angle fill]
  {:type :arc :center center :radius radius
   :start-angle start-angle :end-angle end-angle :fill fill})

(defn ring-sector-motif
  "Generate motif primitives for one angular sector of a ring.
   Recursion depth controls complexity."
  [inner-r outer-r sector-angle depth palette rng]
  (case depth
    0 ;; simple color band
    [{:type :annular-sector :inner-r inner-r :outer-r outer-r
      :start-angle 0 :end-angle sector-angle
      :fill (nth palette (int (* (rng) (count palette))))}]
    1 ;; petal arcs
    (let [mid-r   (/ (+ inner-r outer-r) 2.0)
          petal-r (/ (- outer-r inner-r) 2.5)]
      [(petal-arc (polar->cart mid-r (/ sector-angle 2.0))
                  petal-r 0 (* 2 Math/PI) (first palette))])
    ;; depth 2+ : subdivide and recurse
    (let [mid-r (/ (+ inner-r outer-r) 2.0)]
      (concat
        (ring-sector-motif inner-r mid-r sector-angle (dec depth) palette rng)
        (ring-sector-motif mid-r outer-r sector-angle (dec depth) (rest palette) rng)))))

(defn replicate-sector
  "Apply D_n symmetry: rotate sector primitives n times."
  [sector-primitives n]
  (let [angle-step (/ (* 2 Math/PI) n)]
    (mapcat (fn [i]
              (let [theta (* i angle-step)]
                (map #(assoc % :rotation theta) sector-primitives)))
            (range n))))

(defn torana-gates
  "Four rectangular gate cutouts at cardinal directions."
  [width depth]
  (let [half-w (/ width 2.0)]
    [{:type :rect :id :torana-north :center [0.0 1.0]  :w width :h depth}
     {:type :rect :id :torana-east  :center [1.0 0.0]  :w depth :h width}
     {:type :rect :id :torana-south :center [0.0 -1.0] :w width :h depth}
     {:type :rect :id :torana-west  :center [-1.0 0.0] :w depth :h width}]))

(defn generate
  "Pure mandala generator. Returns art data map."
  [{:keys [seed params]}]
  (let [rng    (make-rng seed)
        {:keys [symmetry-order ring-count ring-radii motif-depths
                phase-offsets petal-count-per-ring bindu-radius
                torana-width torana-depth palette]} params
        sector-angle (/ (* 2 Math/PI) symmetry-order)

        ;; Layer 0: square boundary + torana gates
        boundary-layer
        {:id :square-boundary :z-index 0
         :primitives
         (concat
           [{:type :polygon
             :points [[-1 -1] [1 -1] [1 1] [-1 1]]
             :fill nil :stroke "#1A1A1A" :stroke-width 0.008}]
           (torana-gates torana-width torana-depth))}

        ;; Layer 1: central bindu
        bindu-layer
        {:id :bindu :z-index 1
         :primitives [{:type :circle :center [0.0 0.0]
                        :radius bindu-radius :fill "#E34234"}]}

        ;; Layers 2..k+1: concentric rings
        ring-layers
        (map-indexed
          (fn [i radius]
            (let [inner-r  (if (zero? i) bindu-radius (nth ring-radii (dec i)))
                  outer-r  radius
                  depth    (nth motif-depths i 1)
                  phase    (nth phase-offsets i 0.0)
                  sector   (ring-sector-motif inner-r outer-r sector-angle depth palette rng)
                  rotated  (replicate-sector sector symmetry-order)]
              {:id (keyword (str "ring-" i)) :z-index (+ 2 i)
               :primitives (map #(update % :rotation (fnil + 0.0) phase) rotated)}))
          ring-radii)]

    {:seed    seed
     :artform :mandala
     :params  params
     :palette (mapv (fn [p] {:name (name p) :hex (get pigment-hex-map p)}) palette)
     :layers  (into [boundary-layer bindu-layer] ring-layers)
     :metadata {:artform-family :radial-symmetry
                :visual-invariants [:n-fold-symmetry :square-outer-bound
                                    :four-torana-gates :central-bindu
                                    :dense-ring-fill :outward-complexity]}}))
```

## Cultural Guard Rails

- **DO**: Generate sacred geometry with mathematical precision. Mandalas are meditation instruments.
- **DO**: Maintain perfect symmetry — imperfection is not "artistic license" in mandala tradition.
- **DO NOT**: Add figurative imagery (faces, animals, landscapes) inside the mandala. It is abstract geometric.
- **DO NOT**: Use asymmetric or "organic" layouts. Mandala is rigid mathematical order.
- **DO NOT**: Omit the square boundary. A circle-only design is a rosette, not a mandala.
