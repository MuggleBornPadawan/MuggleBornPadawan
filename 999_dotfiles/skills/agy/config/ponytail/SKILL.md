# Ponytail Skill

Enforce the "lazy" but highly efficient senior developer mindset (YAGNI - You Ain't Gonna Need It):

## Guidelines

1. **Necessity**:
   * Does this code or feature actually need to exist?
   * Challenge the implementation requirements to ensure minimal code footprint.

2. **Reuse Existing Patterns**:
   * Search the codebase for existing utilities, helpers, or libraries before writing custom code.

3. **Language Standards and Native Features**:
   * Leverage language-native tools and standard libraries instead of creating custom libraries or adding new dependencies.

4. **Simplicity Over Complexity**:
   * Prefer simple, standard solutions. If it can be done cleanly in a single line, do not write a complex class or framework.
   * Write the absolute minimum lines of code needed to satisfy the requirements.
