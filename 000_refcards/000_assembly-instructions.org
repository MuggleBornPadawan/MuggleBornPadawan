* Overview
You need only ~25 instructions to read 90% of compiler output.
Goal: read, not write. Focus on x86-64 (Intel syntax). ARM64 uses same ideas with different names.

* Table — Core Instructions

| Category  | Mnemonic | What it does                            | Example              | Notes                        |
|-----------+----------+-----------------------------------------+----------------------+------------------------------|
| Move      | mov      | Copy data reg<->reg, mem<->reg          | mov eax, 5           | Most common op, ~60% of code |
| Move      | movzx    | Move and zero-extend (small -> large)   | movzx eax, bl        | Use for byte -> int          |
| Move      | movsx    | Move and sign-extend                    | movsx eax, bl        | Keeps sign for negative      |
| Move/Math | lea      | Load address / cheap math               | lea eax, [rbx+rcx*4] | No memory read, just math    |
| Math      | add      | Add                                     | add eax, 3           | Sets flags                   |
| Math      | sub      | Subtract                                | sub eax, 1           | Sets flags                   |
| Math      | imul     | Signed multiply                         | imul eax, ebx        |                              |
| Math      | inc      | Add 1                                   | inc eax              |                              |
| Math      | dec      | Subtract 1                              | dec eax              |                              |
| Math      | neg      | Negate (0 - x)                          | neg eax              |                              |
| Logic     | and      | Bitwise AND                             | and eax, 0xFF        |                              |
| Logic     | or       | Bitwise OR                              | or eax, ebx          |                              |
| Logic     | xor      | Bitwise XOR (xor eax,eax = zero)        | xor eax, eax         | Common zero idiom            |
| Logic     | not      | Flip all bits                           | not eax              |                              |

* Example — Casey demo 5+3-1 = 7

#+BEGIN_SRC asm
mov eax, 5      ; eax = 5
add eax, 3      ; eax = 8
sub eax, 1      ; eax = 7
ret             ; return 7 in eax
#+END_SRC

* Tips
- Use godbolt.org with -O2, Intel syntax, to see these ops.
- Intel vs AT&T: mov eax,5 (Intel) = movl $5, %eax (AT&T) — same op.
- Focus on registers first (eax, ebx, ecx, edx, rsi, rdi, rsp, rbp), ignore [rsp+8] at start.
- ARM64 map: mov->mov, ldr/str->mov mem, b.eq->je, bl->call, ret->ret
