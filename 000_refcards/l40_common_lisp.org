* lisp fundamentals
- s-expressions (forms)
- atoms (indivisible units) and lists (divisible units) 
- the first atom - looked up and evaluated as a function, macro or special operator name 
- the rest of the symbols are treated as variables and the form (s-expression) is evaluated 
- prefix notation and parenthesis 
- all inner forms evaluated left-to-right before being passed to function
- repl

** variables
- surrounded by *<x>* as convention to indicate global nature 
- defvar (use setf to mutate) 
- defparamameter 
- let - local variables
- let* - reuse local variables in the same form later
** functions
- all defun are global (top level) functions
- flet and labels are local functions
  - flet is like let, and labels is like let*
  - importantly, this means if you want to do anything recursive you need to use labels
- args
- rest args
- default args
- optional args
- keys args
- dont mix &optional &key parameters
- &optional and &rest are fine 
- &rest and &key - fine
- &key and &rest - error
